# Student Database Management System

A professional Student Database Management System built for MCA Final Year Project. 

## 🚀 Tech Stack
- **Language:** Python 3.x
- **GUI:** CustomTkinter (Modern Tkinter)
- **Database:** SQLite3
- **Reports:** CSV/PDF Export

## 📁 Project Structure
```text
student_management/
 ├── main.py            # Entry point
 ├── db.py              # Database initialization & queries
 ├── login.py           # Authentication module
 ├── dashboard.py       # Main landing page after login
 ├── students.py        # Student records management
 ├── attendance.py      # Attendance tracking
 ├── marks.py           # Academic records & grades
 ├── reports.py         # Exporting & statistics
 ├── assets/            # Images, icons, and styles
 └── database/          # SQLite database file store
```
